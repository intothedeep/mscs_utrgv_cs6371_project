1 The assignment problem

  • The baseline is the central-place foraging algorithm (CPFA).
  • A robot leaves the nest and searches for food. On a find, it leaves a pheromone waypoint on the server.
  • Robots visit food clusters many times. They never visit other places.
  • If every visited point goes to the server, there are too many points. A server that scans all of them each time pays a high cost.
  • The grid method of the professor's MS student has a limit. When the arena is large, the cells are large. Then it loses efficiency.
  • Goal: organize the points more efficiently, so the server finds empty places fast. Then raise the score.
